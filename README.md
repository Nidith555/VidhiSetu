# VidhiSetu

**Multilingual AI-powered legal assistance platform for India.**

VidhiSetu is intended to make legal information more accessible to citizens, law students, and legal professionals. This repository is being organized as a shared home for the Android application and its supporting services.

## Repository status

The repository currently contains an initial Flask backend snapshot. The complete Android Studio project, AI-agent implementation, and the team's full RAG implementation have **not yet been added**. Please do not treat this repository as a complete, buildable release until those components are committed and tested.

## Initial backend capabilities

- Flask health/status endpoints.
- Civilian legal-intake follow-up questions, one at a time.
- Hindi (`hi`) and Telugu (`te`) response-language instructions for the civilian intake endpoint.
- Legal-news aggregation from the Press Information Bureau RSS feed and the Supreme Court of India website.

See [backend/README.md](backend/README.md) for setup, environment variables, API examples, and known limitations.

## Planned components

These are planned repository areas, not yet included implementations:

- **Android app:** Kotlin, XML layouts, navigation, onboarding, profile, and localized Android resources.
- **AI agents:** the team's agent workflows and orchestration.
- **RAG integration:** interface and configuration for retrieving relevant legal provisions and source passages.
- **Legal verification:** citation validation, evidence-support checks, and evaluation tests.
- **Documentation:** architecture, API contracts, and contributor setup.

The team's RAG implementation should be added by its owner, or integrated with their agreement and correct attribution.

## Safety and privacy

- Never commit API keys, access tokens, passwords, Firebase service-account files, keystores, or local machine configuration.
- Keep real user legal records and personal information out of test fixtures and public commits.
- Legal information generated by an AI system can be incomplete or incorrect. Verify statutes and citations against official sources and consult a qualified lawyer for case-specific advice.

## Contribution workflow

1. Work on a dedicated branch.
2. Keep commits focused and descriptive.
3. Add or update tests when changing backend behaviour.
4. Do not claim that a feature is complete until it has been tested.
5. Review all files for credentials and personal data before pushing.
